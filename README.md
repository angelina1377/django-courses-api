# Django Courses API

Учебный REST API для управления курсами и пользователями в системе LMS (Learning Management System). Проект реализован на Django и Django REST Framework.

## Технологии

- Python 3.10+
- Django 4.x
- Django REST Framework
- SQLite (для локальной разработки)

## Структура проекта

- `config/` — настройки проекта (settings, urls, WSGI/ASGI).
- `lms/` — логика курсов и уроков (модели, сериализаторы, вьюсеты).
- `users/` — управление пользователями и аутентификация.
